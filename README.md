# docs

Documentation and howtos for building your own BSD from the wtfbsd templates

Start here:

1. **[Quickstart: your first customized desktop in one sitting](guide/00-quickstart.md)**,
   a worked example on FreeBSD 16, from fork to a booted image with your
   own wallpaper, greeter theme and one extra application.
2. **[The ecosystem playbook](guide/README.md)**, a stage-by-stage guide
   to making, building, publishing and maintaining your own BSD
   distribution.
3. **[Security](guide/08-security.md)**, how to review and audit the
   work, what the product ships hardened and audited, and the
   `SECURITY.md` every repository carries ([template](templates/SECURITY.md)).

Part of the [wtfbsd](https://github.com/wtfbsd) template set. See [wtfbsd.ai](https://wtfbsd.ai).

Status: the playbook covers every stage; the parts the templates do not automate yet are marked as such on each page.
